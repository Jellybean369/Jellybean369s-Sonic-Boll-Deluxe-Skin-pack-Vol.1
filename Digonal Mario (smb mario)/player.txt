======= SMB1 SETTINGS ================================
======================================================

----- "waitanim" decides whether the skin should enable the "wait" animation -----
^^ this is a true/false (1/0) value
waitanim=0

----- "runanim" decides whether the skin has a running animation (being called "maxrun") or not -----
^^ this is a true/false (1/0) value
runanim=0

----- "djanim" decide whether the skin should enable the "doublejump" animation (used for feather) -----
^^ these are true/false (1/0) values
djanim=0

----- "fallanim" and "fallinsteadofairwalk" decide whether the skin should allow for the use of fall animations -----
^^ these are true/false (1/0) values
fallanim=0
fallinsteadofairwalk=0

----- "bonkanim" decides whether the skin should allow for the use of the "bonk" animation -----
^^ these are true/false (1/0) values
bonkanim=0

----- "switchfireanims" allows you to use seperate animations for firing with the fire flower (smb1 style), essentially allowing you to do stuff like smb1's hand raised while still playing the lower half of the walk animation -----
^^ this is a true/false (1/0) value
switchfireanims=1

----- "tauntanim" decides whether the skin should allow for the use of the taunt button C (sprite used is called "taunt") -----
^^ this is a true/false (1/0) value, when C is pressed, a random frame of the sprite will show
tauntanim=1

----- "palettemode" decides whether to use SMB1mario's Star palette system or not -----
^^ "SMB1MARIO" uses the Star palette system, "REGULAR" ignores that and uses the normal system
palettemode=SMB1MARIO

======================================================
